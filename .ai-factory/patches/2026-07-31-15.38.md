# Stabilize graceful-degradation test timeout

**Date:** 2026-07-31 15:38
**Files:** test/editor/components/notion/notion-editor.graceful-degradation.integration.test.ts
**Severity:** low

## Problem

The local-editor graceful-degradation test intermittently exceeded Vitest's default 10-second timeout during full-suite concurrency.

## Root Cause

The test imports and mounts the editor dependency graph. Its behavior assertions were correct, but cold module transformation and concurrent workers could consume the default timeout budget.

## Solution

Applied a 30-second timeout to this integration test only. The complete suite now passes with all behavior checks unchanged.

## Prevention

- Give cold-start integration tests a local timeout that reflects their setup cost.
- Keep unit tests on Vitest's default timeout so slow regressions remain visible.
