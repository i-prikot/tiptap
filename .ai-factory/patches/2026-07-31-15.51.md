# Restore the icon generator lint limit

**Date:** 2026-07-31 15:51
**Files:** scripts/generate-icons.mjs, scripts/resolve-windows-icon-source-directory.mjs, test/scripts/generate-icons.test.mjs
**Severity:** low

## Problem

The pre-commit ESLint task rejected `scripts/generate-icons.mjs` because the
Windows-specific source-directory validation increased the file to 325 lines,
exceeding the 300-line maximum.

## Root Cause

The platform-specific directory-resolution implementation was added directly
to an already near-limit orchestrator script. The lint policy applies to
physical file length, so the additional behavior made commits fail.

## Solution

Moved the Windows-specific directory resolution and icon-directory path helper
to a focused sibling module. Updated the fixture setup to copy that module when
it runs a generated-script copy.

## Prevention

- Keep platform-specific filesystem behavior in focused helper modules when a
  script is close to its configured size limit.
- Run the script's native `node --test` suite after changing fixture-copy
  dependencies.
