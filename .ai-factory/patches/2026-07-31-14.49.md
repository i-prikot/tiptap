# Restore the complete Vitest suite

**Date:** 2026-07-31 14:49
**Files:** focused editor, playground, and script test files; `apps/playground/src/components/CtaPopup.vue`
**Severity:** medium

## Problem

`npm test` had ten failures after editor lifecycle, localization, and scoped-overlay changes. Several tests still expected English copy, a body-level teleport, synchronous editor construction, or deprecated collaboration setup errors.

## Root Cause

The tests were coupled to pre-refactor component boundaries and default UI behavior instead of providing required parent context or waiting for asynchronous initialization. The CTA also initially targeted `body` before the host overlay element was mounted.

## Solution

Updated the test harnesses to provide their parent context, attach rendered UI to the document where appropriate, and assert the configured Russian default locale and current graceful-degradation behavior. Delayed CTA rendering until its scoped overlay target exists.

## Prevention

- Test localized controls under an explicit locale or the documented default locale.
- Mount teleported child components below a parent that provides their target.
- Await async component initialization after moving editor construction behind promises.
- Do not render a host-scoped teleport until its target ref is available.
