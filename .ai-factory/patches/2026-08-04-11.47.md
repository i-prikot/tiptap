# Stabilize editor integration test setup

**Date:** 2026-08-04 11:47
**Files:** test/playground/host-overlay-target.test.ts, test/editor/components/notion/notion-editor.graceful-degradation.integration.test.ts
**Severity:** low

## Problem

The playground overlay and graceful-degradation integration tests timed out
while loading unrelated UI dependencies inside their `it` callbacks.

## Root Cause

The host-boundary test imported the full Tooltip implementation despite only
needing to exercise the injected Teleport target. The graceful-degradation
test dynamically imported NotionEditor after starting its timeout, so SFC
transformation and module resolution consumed the test budget.

## Solution

Use a lightweight overlay probe in the host test and clean up its CTA mock.
Hoist the EditorProvider mock and statically import NotionEditor so module
preparation finishes before graceful-degradation assertions begin.

## Prevention

- Keep host-boundary tests focused on the scoped overlay contract.
- Hoist stable component mocks and imports outside timed test callbacks.
- Reset temporary module mocks in shared test cleanup.
