# Stabilize publish artifact fixtures on Windows

**Date:** 2026-08-04 12:01
**Files:** test/scripts/verify-publish-artifacts.test.ts
**Severity:** low

## Problem

The publish artifact verifier test intermittently failed before verification
started with `spawnSync tar ETIMEDOUT`.

## Root Cause

Fixture archives are created by the external `tar` executable. Its one-second
startup and completion timeout was too short under parallel Windows test load.

## Solution

Increased the fixture-only archive creation timeout to ten seconds while
retaining a finite limit for genuinely hung processes.

## Prevention

- Use realistic timeouts for external process fixtures on Windows CI.
- Keep verification assertions separate from fixture creation failures.
